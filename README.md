## Broken Link Auditing Capabilities

* **Comprehensive Hyperlink Scanning**: Full extraction and validation of internal and outbound navigational links.
* **HTTP Status Code Mapping**: Pinpoint dead links (404), gone resources (410), and server faults (500-level).
* **Crawl Budget Optimization**: Prevent link equity dilution and wasted crawler activity across large enterprise architectures.
* **Anchor Text Analysis**: Review anchor labeling for optimal user clarity and compliance with web standards.
* **Link Integrity Score**: Technical rating from 0 to 100 with actionable remediation lists.

***

## Installation and Execution

Runs on Python 3.8 or higher with zero third-party package dependencies.

```bash
git clone https://github.com/TAVARDT-USA/broken-links-checker-us.git
cd broken-links-checker-us
python broken_links_scanner.py https://enterprise.com
```

Format output as JSON:

```bash
python broken_links_scanner.py https://enterprise.com -json
```
